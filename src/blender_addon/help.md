# Как пользоваться Asset Assistant

> Короткая шпаргалка. Полный гайд — в репозитории: `docs/15-features-guide.md`.

## Правило номер один

**Если задачу можно решить кнопкой — решайте кнопкой.** Кнопка работает
мгновенно и всегда. Чат с локальной моделью на CPU отвечает минутами и иногда
ошибается.

Кнопки в панели **AI** (в сайдбаре 3D-вьюпорта, `N` → вкладка **AI**):

| Блок | Кнопка | Что делает |
|---|---|---|
| Текстуры | **Упаковать** | текстуры вшиваются в `.blend` — проект больше не зависит от папки |
| Текстуры | **Пути** | пути становятся относительными, потерянные файлы находятся сами |
| Материалы | **Доктор** | показывает, что в материалах сломано (то, что не видно во вьюпорте) |
| Материалы | **Починить** | чинит безопасное: цветовые пространства, нормали, отключённые выходы |
| Материалы | **PBR из папки** | собирает материал из папки с картами и вешает на объект |
| Бейкинг | **Запечь** | процедурный материал → карты в папку + обычный материал на объект |
| Процедурные | **Процедурный** | собрать материал по описанию (16 рецептов) |
| Процедурные | **Авторские материалы** | собрать один из авторских пресетов (ржавый металл, потёртый металл…) |
| UV | **Развернуть**, **Плотность**, **Атлас** | развёртка, одинаковая плотность текслей, общий атлас |
| Экспорт | **Проверка экспорта** | готов ли проект к glTF/FBX |
| Массовые | **Назначить выделению**, **Кто использует** | назначить материал всему выделению, найти пользователей |

## Пять вопросов, которые стоит попробовать

1. **«Что не так с материалами?»** — ассистент назовёт конкретные проблемы.
2. **«Сделай ржавый металл»** — соберётся авторский пресет.
3. **«Сколько тут UV-плотность?»** — ассистент покажет проблему с плотностью.
4. **«Запеки и скажи, что готово к экспорту»** — полный цикл.
5. **«Сделай как на другом объекте, но темнее»** — ассистент перенесёт настройки.

## Когда что делать

| Хочу | Что нажать |
|---|---|
| Материал из картинок | **PBR из папки** |
| Процедурный материал | **Процедурный** или **Авторские материалы** |
| Проверить, что сломано | **Доктор** → **Починить** |
| Разложить по UV | **Развернуть** → **Атлас** |
| Отдать в игру | **Запечь** → **Проверка экспорта** |
| Проект должен ездить | **Упаковать** + **Пути** |

## Код от ассистента

Ассистент может написать код — последний блок ```python в ответе запускается
кнопкой **«Выполнить код»**. Кнопка одноразовая: после запуска блок
сворачивается в одну строку, а сам код остаётся в текстовом редакторе
(кнопка **«Скрипты»** рядом с *Shader Editor*).

Если код выполнился с ошибкой — текст ошибки будет в чате, а сцена не
пострадает: выполнение можно отменить (`Ctrl+Z`).

## Чего ассистент не умеет

- сам рисовать материалы «по вкусу» — на маленькой локальной модели это
  получается плохо; бери **Авторские материалы** или пиши числа сам;
- работать без модели: кнопки работают всегда, чат — никогда без модели;
- отменять разрушающие операции сам: такие инструменты спрашивают подтверждение.

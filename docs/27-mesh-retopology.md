## 27.1. Зачем это

Хай-поли скульп и игровая сетка — это разные объекты. Скульп: миллион
треугольников, без UV, для движка слишком тяжёлый. Игровая сетка: квады,
известный бюджет, своя развёртка.

Между ними стоит реторопология. Раньше её не было в аддоне, и вопрос «а как
же сетку-то» оставался открытым.

### Что мы НЕ делаем

Свой квад-ремешер. Quad Remesher — коммерческий GPU-плагин, его качество мы не
повторим, а бюджет уйдёт в пустоту. Мы делаем **дирижёра**: выбрать глубину
под бюджет, притянуть результат к скульпту, почистить и показать отчёт.

> ⚠️ В Blender 5.2 **встроенного квад-ремешера больше нет**: оператор
> `bpy.ops.quadriflow_remesh` удалён. Остались только модификаторы `Remesh`
> (Blocks / Smooth / Sharp / Voxel) и `Decimate`. Квады даёт Blocks (и Voxel).

## 27.2. Доктор по сетке

Кнопка **«Проверить сетку»** (вкладка «Сетка») говорит, что с сеткой не так:

| Проверка | Что значит |
|---|---|
| треугольники вместо квадов | в игре каждая грань — два треугольника, бюджет тает |
| рёбра с несколькими гранями | сетка не замкнута, её нельзя запекать и нельзя отдать движку |
| граничные рёбра | дыры в сетке |
| совпадающие вершины | «висящие» куски, которые ломают нормали |
| висящие вершины и рёбра без граней | мусор в сцене |
| полюса (5+ граней вокруг вершины) | там ломается сглаживание |
| вытянутые треугольники | «иголки», которые портят нормали |
| нет UV | текстурировать нечем |
| нет материала | нечего показывать в игре |
| превышение бюджета | считается в треугольниках, как считает рендер |

### Замер на реальном ассете

`E:\ASSETS\Cryptan\крестьянин.glb` (сгенерирован в Hunyuan, поэтому без UV и
материалов):

```
geometry_0: 105793 verts, 211618 faces (0 quads, 211618 tris, 0 n-gons)
  triangles the renderer sees: 211618
  budget 20000: over
  doubled vertices: 70, loose: 0
  poles (5+ faces around a vertex): 103364
  needle triangles: 11650
  UV layers: none
  materials: none
```

Сетка при этом **замкнутая**: 0 не-манifold рёбер, 0 дыр. То есть чинить
нечего — её нужно облегчить.

## 27.3. Ретопология

Кнопка **«Ретопология»** (вкладка «Сетка»). Настройки живут на сцене:

| Поле | По умолчанию | Смысл |
|---|---|---|
| Бюджет треугольников | 20 000 | сколько треугольников должен весить игровой меш |
| Прижать к скульпту | вкл | притянуть новую сетку к исходной, чтобы сохранить силуэт |
| Уровней LOD | 3 | сколько уровней детализации построить |

Бюджет — **число**, а не пресет: мобилка, ПК, конкретный проект — решает
пользователь.

### Что происходит по шагам

```
1. исходник копируется в новый объект «<Имя>_Retopo» (оригинал не трогаем)
2. перебор глубин октаэдрального ремеша: ищем ту, что не превышает бюджет
3. ремеш Blocks (quads) на найденной глубине
4. Shrinkwrap: PROJECT (движение по нормали) + NEAREST_SURFACEPOINT (притяжение)
5. чистка: нормали наружу, гладкие грани, резкие рёбра по углу 40°
6. отчёт: квады, треугольники, отклонение от скульпта, время, не-манifold рёбра
```

### Замер на том же ассете (бюджет 20 000)

```
depth=6, faces=3632, quads=3632, треугольников 7264
время 2.5 с
отклонение от скульпта: среднее 0.00 мм, максимум 0.00 мм
```

Результат: **3 632 квада** (7 264 треугольника) — в пределах бюджета,
и стоящие на скульпте с точностью до нуля.

### Три вещи, которые пришлось измерить, а не угадать

**1. PROJECT один не работает.** Он двигает вершину вдоль её нормали, и луч,
направленный от поверхности, не попадает в неё. Замер на сфере:

| Рецепт | отклонение среднее | максимум |
|---|---|---|
| PROJECT | 93.56 мм | 444.51 мм |
| NEAREST_SURFACEPOINT | 0.00 мм | 0.00 мм |
| PROJECT + NEAREST | 0.00 мм | 0.00 мм |

Поэтому делаем оба шага: PROJECT ведёт вершину по нормали (так форма не
«плывёт» вбок), NEAREST добивает промахи.

**2. Вершины нельзя сливать.** Октаэдральный ремеш оставляет тысячи точно
совпадающих вершин, и их слияние складывает поверхность в местах, где она
касается сама себя:

| Что сделали | не-манifold рёбер |
|---|---|
| после ремеша | 165 |
| после сжатия с допуском 0.2 мм | **4 154** |
| после сжатия с допуском 2 микрона | 4 154 |

Слияние вершин **убрано**. Совпадающие вершины остаются, и доктор их покажет
(«doubled vertices: 900»).

**3. Разрешение ремеша — степень двойки.** Глубина октаэдры даёт не плавный
 ряд, а скачок: 12 → 108 → 444 → 888 → … треугольников. Попасть в бюджет
точно нельзя, поэтому берётся ближайший **не превышающий** бюджет, а в отчёт
пишется, какой был бы следующий шаг:

```
the remesh only doubles the resolution: the next step would be 31152
triangles, over the budget of 20000
```

### Остатки честно

Результат ремеша не идеален: 44 не-манifold ребра и 900 совпадающих вершин
на этом ассете. Это наследие октаэдрального ремеша, а не наша ошибка. Отчёт
говорит об этом прямо, и доктор покажет то же самое.

## 27.4. Цепочка LOD

Кнопка **«Цепочка LOD»** строит рядом с объектом `LOD1`, `LOD2`, `LOD3` —
каждый легче предыдущего вдвое.

| Исходная сетка | Метод |
|---|---|
| квадная (≥90 % квадов) | `Decimate / Unsubdivide` — квады остаются квадами |
| треугольная | `Decimate / Collapse` с долей ½ⁿ |

⚠️ Цепочку строят **по игровой сетке**, а не по хай-поли. То есть сначала
реторопология, потом выделяем результат и жмём «Цепочка LOD».

## 27.5. Вкладки панели

Раньше панель показывала все кнопки сразу, и в глазах мелькало. Теперь
инструменты разложены по этапам пайплайна, и на экране только те, что
относятся к текущей задаче.

| Вкладка | Что внутри |
|---|---|
| **Текстуры** | PBR из папки, текстуры в материалы, доктор по материалам и починка, упаковка, пути, отчёт по текстурам, массовые операции, процедурные материалы |
| **Сетка** | проверить сетку, ретопология, цепочка LOD, бюджет и настройки |
| **UV** | развёртка, плотность текселей, проверка, исправление перекрытий, атлас, экспорт комплекта, импорт атласа |
| **Запечь** | запекание, нормали из высоты, размер/сэмплы/карты, ORM, превью |
| **Экспорт** | проверка экспорта, GLB, FBX |

Технически это один `EnumProperty` на сцене (`gaa_tab`), нарисованный с
`expand=True` — так Blender показывает ряд переключателей. Подписи приходят
из i18n через callback, поэтому язык переключается без перерегистрации аддона.

Вкладку можно переключить и из кода: `bpy.context.scene.gaa_tab = "EXPORT"`.

## 27.7. Что проверить руками

1. Открыть `крестьянин.glb`, вкладка **«Сетка»** → «Проверить сетку»: должны
   быть 211 618 треугольников, 70 совпадающих вершин, 11 650 иголок, нет UV.
2. Поставить бюджет 20 000 → «Ретопология»: должен появиться
   `geometry_0_Retopo` с квадами, отклонение 0 мм, время около 3 с.
3. Исходный `geometry_0` не должен измениться: 105 793 вершины, 211 618 граней.
4. Выделить `geometry_0_Retopo` → «Цепочка LOD»: три объекта, каждый легче.

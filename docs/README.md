# Asset Assistant — учебник по коду

Эта папка — не справочная документация «для галочки», а **учебник**: он объясняет
не только *что* делает код, но и *почему* именно так. Рассчитан на человека,
который не знает Blender API и хочет понимать каждую строчку аддона.

Материал упорядочен: главы 1–2 дают фундамент (API и архитектура), 3–5
разбирают конкретные модули аддона, глава 6 — задел под следующий этап
(материалы и текстуры).

## Как читать

1. Если ты совсем не трогал Blender API — начни с главы 1. Там есть примеры,
   которые можно вставить в **Text Editor** Blender (окно `Scripting`) и нажать
   `Run Script`, чтобы увидеть результат своими глазами.
2. Глава 2 — «карта местности»: держи её открытой, когда читаешь главы 3–5.
3. Главы 3–5 — разбор реального кода аддона. У каждого фрагмента указан файл.
4. Глава 6 — «кулинарная книга» для следующего этапа; её можно
   использовать как справочник готовых сниппетов.

## Обозначения

- 🧪 — пример, который можно выполнить прямо в Blender (Text Editor → Run Script).
- ⚠️ — типичная ловушка.
- 📦 — отсылка к реальному файлу аддона.

## Быстрая навигация по репозиторию

```
src/blender_addon/     — код, который живёт внутри Blender
    __init__.py        — точка входа: register()/unregister(), хоткей
    preferences.py     — настройки аддона (язык, бэкенд, ширина чата)
    operators.py       — кнопки: отправить, стоп, очистить, запустить код
    ui.py              — отрисовка чата и панели в трёх редакторах
    state.py           — состояние чата + мост к воркеру (JSONL + таймеры)
    snapshot.py        — краткое описание сцены для промпта
    prompts.py         — системные промпты (RU/EN)
    i18n.py            — таблицы строк RU/EN и функция T()
src/asset_core/        — код, который НЕ зависит от Blender
    worker.py          — процесс-сайдкар: говорит с моделью
    transport.py       — HTTP-клиент Ollama/OpenAI (stdlib only)
tools/build_addon.py   — сборка установочного zip расширения
```

> Текст учебника — на русском, потому что он делается для изучения кода. Сам код и
> комментарии в нём — на английском (единый стиль проекта), и корневой `README.md`
> тоже английский. Двуязычность (RU/EN) относится к **интерфейсу самого аддона** и к
> этому учебнику отношения не имеет.
